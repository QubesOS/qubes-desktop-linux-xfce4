# Qubes Xfce Desktop Settings

This repository (the `xfce4-settings-qubes` package) is part of
[Qubes OS](https://www.qubes-os.org). It provides the default Xfce4 desktop
configuration for dom0 (the GUI domain): the panel layout, the Qubes
application menu, keyboard shortcuts for managing qubes (such as pausing all
qubes or `qvm-xkill`), and the session, power-manager, and screen-locking
settings. It swaps Xfce's stock configuration files for Qubes versions so the
desktop works with Qubes out of the box.

For an overview of the Qubes OS desktop, see
[User Interface](https://doc.qubes-os.org/en/latest/introduction/getting-started.html#user-interface).
